Validate the shared Multi-Agent workflow for one feature.

Constraints:
- local open-source models only (qwen2.5:0.5b, llama3.1:8b)
- evidence comes from the feature's database API, never a .db file
- use only the supplied evidence

Required agents:
- Planner Agent (plan_workflow)
- Worker Agent (generate_output)
- Reviewer Agent (review_output)

Requirements:
- coordinator runs Planner and Worker, then Reviewer with the plan
- Worker evidence count above zero
- human decision recorded (Accept, Partially Accept, Reject)
- workflow_history.jsonl and coordination_audit.jsonl updated
- feature backend route present for UI integration

Maximum 60 words.
